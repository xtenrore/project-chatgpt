Connect ChatGPT

  1. Install the Project Supervisor Bridge extension in Chrome or Edge.
  2. Stay logged into chatgpt.com in that browser.
  3. Open the extension and click Open Supervisor. It pairs this site locally.
  4. Paste the exact ChatGPT Project/conversation URL into a Supervisor job.

The computer running the extension must remain awake. ChatGPT usage limits are respected and pause the job.
